# Evidence

Everything in this folder is real output captured from the PipeGen run. Nothing here is mocked.

| File | What it is |
|---|---|
| `pipeline_ir_graph.png` | Screenshot of PipeGen's Pipeline IR (PIR) node graph |
| `tensorrt_speed_report.png` (+ any report file PipeGen writes) | PipeGen's TensorRT compile and speed report |
| `live_run.png` | Live DeepStream run on the GPU, with the alert subscriber terminal visible |
| `sample_json.txt` | 10 real lines of JSON metadata written by the pipeline |
| `sample_mqtt.txt` | 10 real MQTT messages received on `junction/counts` |
